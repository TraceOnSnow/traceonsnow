## Selected Projects

A self-hosted party game room for friends: guessing, bluffing, voting and card games in the browser, hosted by a shared AI.

`TypeScript` · `React` · `Colyseus` · `PostgreSQL` · `Drizzle` · `LLM` · `Docker`

### 🎮 [SteamGuess](https://github.com/TraceOnSnow/SteamGuess) · [play](https://steamguess.traceonsnow.com)

Guess the Steam game in ten tries from clues such as price, peak players, reviews, release date and tags. Daily challenge, themed presets and multiplayer rooms.

`TypeScript` · `React` · `Node.js` · `SQLite` · `Socket.IO` · `Docker`

### 🗂️ [obsidian-workflow](https://github.com/TraceOnSnow/obsidian-workflow)

A Markdown and Obsidian content library with a CLI, reusable Agent Skills, MCP tools, and guarded publishing sync to my website.

`Python` · `Obsidian` · `MCP` · `Agent Skills` · `Payload CMS`

`Python` · `LLM` · `Markdown`
